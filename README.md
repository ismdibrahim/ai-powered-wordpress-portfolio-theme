# DevCanvas — AI-Powered WordPress Portfolio Theme

A classic WordPress portfolio theme built with AI assistance. Includes a customizable header and footer and a selectable Homepage template with hero, toolkit, and services sections.

## Installation

1. Download the repository ZIP from **Code → Download ZIP**.
2. In WordPress, go to **Appearance → Themes → Add New → Upload Theme** and upload the ZIP.
3. Activate **DevCanvas**.

For local development, clone this repository into `wp-content/themes/devcanvas`.

## Configuration

- **Appearance → Customize → Header & Footer:** edit logos, header button, and copyright. Use `{year}` for the current year.
- **Appearance → Menus:** assign a menu to **Header Menu**.
- Edit a page and select the **Homepage** template.
- Open **Meta Boxes → Homepage — Section Settings** to edit the Hero, Toolkit, and Services groups. Content is saved separately for each page.
- To use that page as the site's front page, select it under **Settings → Reading**.

Replace the sample name, copyright, images, and links before using the theme for your portfolio. The default `#projects` and `#contact` links are placeholders for sections not yet implemented. Google Fonts requires an internet connection.

The current theme includes the hero, toolkit, and services sections; the remaining original HTML homepage sections have not yet been converted. `screenshot.png` is the starter theme preview.
